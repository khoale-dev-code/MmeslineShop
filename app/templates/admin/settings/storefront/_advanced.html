Advanced Layout Data

Dữ liệu JSON của trang chủ

Đây là dữ liệu đầy đủ của toàn bộ block trong Storefront Builder. Mỗi block có ID riêng, type riêng, thứ tự riêng và settings riêng nên có thể lặp cùng loại không giới hạn.

Lưu vào storefront.homepage_layout

Developer Tools

Kiểm tra, sao chép, import và export layout

Tab này dành cho kiểm tra dữ liệu kỹ thuật. Bạn có thể copy JSON, validate cấu trúc, export layout ra file, hoặc import layout từ file JSON khác. Khi chỉnh trực tiếp JSON, hãy bấm Áp dụng JSON trước khi lưu giao diện.
